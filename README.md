# SITE-DO-PROJETO-IFA
### DISCIPLINA FÍSICA E TECNOCIÊNCIA - IFA 2º SEMESTRE 2026

## Descrição
Este é o Site do Projeto Integrador da Disciplina IFA-2026.

**Tema: ACESSIBILIDADE DA VISÃO**

O site aborda os seguintes tópicos:
- Divulgação Científica
- Limites da Visão
- Óptica Geométrica
- Propriedades da Luz
- Espelhos
- Refração da Luz
- Fibra Ótica
- Luz e Cores
- Reflexão
- Lentes e Elementos de Definição
- Lentes e Aplicações
- Lentes e Informações de Imagens
- Óptica do Olho Humano

## Objetivo
Promover a inclusão, a autonomia e a permanência acadêmica de estudantes com deficiência visual ou baixa visão, por meio de adaptações estruturais e divulgação científica.

- HTML
- CSS
- JavaScript
